## Ciencia-de-datos

Todos mis proyectos de ciencias de datos del curso "Profesión Cintifico de Datos" con EBAC.

Incluido el proyecto final con le empresa aliada "Reckiit"

Durante mis días de estudio aprendi cosas como:

Modelado Predictivo y Estadístico: Desarrolando la capacidad de implementar modelos complejos como la regresión lineal y modelos ARIMA para realizar pronósticos precisos, como el análisis de series de tiempo en acciones bursátiles.

Análisis Multivariante y Reducción de Dimensionalidad: A través de técnicas como Clustering y PCA (Análisis de Componentes Principales), aprendí a identificar patrones ocultos en grandes volúmenes de datos y a simplificar variables complejas para mejorar la eficiencia de los modelos.

Evaluación Rigurosa de Modelos de Machine Learning: Gracias a los diferentes proyectos, entendí el uso de criterios técnicos como Gini y Entropía para medir la pureza y el rendimiento de los árboles de decisión, asegurando que el analisis de mis modelos sean estadísticamente confiable.

# Aprendisaje de maquina supervisado:

Entrenamos varios modelos utilizando un conjunto de datos que ya contiene las respuestas correctas, conocidas como etiquetas

Existen dos tipos principales de problemas en el aprendizaje supervisado:

## Regresión: Se usa cuando el resultado es un número continuo.

Ejemplo: Predecir el precio de las acciones de empresas como Disney o IBM basado en datos históricos.

Algoritmos comunes: Regresión lineal, ARIMA.

## Clasificación: Se usa cuando el resultado es una categoría o "etiqueta".

Ejemplo: Determinar si un correo es Spam o no, o clasificar especies de dinosaurios basándose en su estructura ósea.

Algoritmos comunes: Árboles de decisión, Random Forest, Máquinas de Soporte Vectorial (SVM).

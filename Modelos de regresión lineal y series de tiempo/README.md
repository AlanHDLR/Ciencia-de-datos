# Regresión lineal y series de tiempo
Tanto la regresión lineal como las series de tiempo son pilares fundamentales del aprendizaje supervisado para entender relaciones entre variables y predecir eventos futuros.

## 1. Modelos de Regresión Lineal
La regresión lineal es un modelo estadístico que busca establecer una relación funcional entre una variable dependiente (lo que queremos predecir) y una o más variables independientes (los demás datos que tenemos).

El objetivo es encontrar la "línea de mejor ajuste" que minimice la distancia entre los datos reales y las predicciones del modelo.

Dentro de los proyectos eh utilizado este modelo para realizar análisis estadísticos y entender cómo una variable afecta directamente a otra dentro de diferentes contextos.

## 2. Modelos de Series de Tiempo
A diferencia de la regresión lineal, las series de tiempo se enfocan en datos recolectados, observados o registrados en intervalos de tiempo secuenciales (diario, semanal, mensual).

Aquí el orden de los datos es crítico porque el valor actual suele depender de los valores pasados(datos historicos).

* Modelo ARIMA: Es uno de los algoritmos más potentes para este análisis.

Dentro del curso ejecute un proyecto de pronóstico bursátil donde aplique modelos ARIMA para predecir los precios de las acciones de corporaciones como Disney, IBM y Walmart.

## Diferencia Clave
Mientras que la regresión lineal intenta explicar el "por qué" o la magnitud de una relación entre variables en cualquier momento, las series de tiempo (como ARIMA) se especializan en el "cuándo" ocurrirá un evento basándose estrictamente en el comportamiento histórico cronológico.

# Aprendisaje no supervisado
En este caso entrenamos modelos con datos que no tienen etiquetas ni respuestas correctas predefinidas. Aquí, el objetivo del algoritmo es actuar como un explorador: debe encontrar por sí mismo estructuras, patrones o agrupaciones ocultas dentro de la información.
Existen 2 tecnicas principales:
## 1. Clustering (Agrupamiento)
Es la técnica de organizar objetos en grupos cuyos miembros son similares de alguna manera.

Nos ayuda para encontrar segmentos o patrones en conjuntos de datos complejos.

## 2. Reducción de Dimensionalidad
Se utiliza para simplificar datos que tienen muchísimas variables, manteniendo solo la información más importante.

Utilización del PCA (Análisis de Componentes Principales), una de las herramientas más potentes para reducir la complejidad de los datos sin perder su esencia.
